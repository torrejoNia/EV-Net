# Additional experiments

Analyses that support design choices in EV-Net. They are not part of the R
package: this folder is listed in `.Rbuildignore`, so it is not included
when the package is built or installed.

| Experiment | Question |
|---|---|
| [signal_directionality_experiment](signal_directionality_experiment/) | When all nodes of the ligand–signaling network are used as seeds, can the signal flow back from downstream nodes to ligands? |
